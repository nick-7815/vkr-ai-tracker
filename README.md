# Шаблон ВКР бакалавра ВолгГТУ на Typst

Шаблон пояснительной записки к выпускной квалификационной работе бакалавра.
Вся вёрстка уже настроена по методическим указаниям — вы пишете только текст.

Оформление соответствует пособию: А. Г. Кравец, М. В. Щербаков. «Выпускная
квалификационная работа бакалавра». — Волгоград: ВолгГТУ, 2024 (раздел 4.1).

## Быстрый старт

1. Нажмите **Use this template → Create a new repository** вверху страницы.
2. Склонируйте свой репозиторий и установите [Typst](https://github.com/typst/typst):

   ```sh
   # macOS
   brew install typst
   # Windows
   winget install --id Typst.Typst
   # Linux
   sudo snap install typst
   ```

3. Запустите сборку с автообновлением:

   ```sh
   typst watch thesis.typ
   ```

   PDF пересобирается за миллисекунды при каждом сохранении. Откройте
   `thesis.pdf` в любом просмотрщике — он будет обновляться сам.

Никаких дополнительных установок не нужно: ни LaTeX, ни Inkscape, ни Python.
SVG-схемы вставляются напрямую.

## Что где лежит

| Путь | Что это |
|---|---|
| `thesis.typ` | Главный файл. Единственное, что настраивается под себя |
| `chapters/` | Текст разделов — здесь вы проводите 99 % времени |
| `other/` | Аннотации на русском и английском, список сокращений |
| `appendices/` | Приложения: листинги, ТЗ, объёмные таблицы |
| `bibliography/references.bib` | Список источников |
| `assets/figures/` | Рисунки и схемы (`.svg`, `.png`, `.jpg`) |
| `lib/vkr.typ` | Вёрстка по методичке. **Трогать не нужно** |
| `examples/showcase.typ` | Витрина: все элементы оформления на одной странице |

## Что шаблон делает за вас

Всё перечисленное настроено и проверено — переделывать вручную ничего не надо:

- поля 30 / 10 / 15 / 20 мм, Times New Roman 14 пт, полуторный интервал,
  выравнивание по ширине, абзацный отступ 15 мм;
- сквозная нумерация страниц внизу по центру; титульный лист и задание входят
  в нумерацию, но номер на них не печатается; аннотации — страницы 4 и 5,
  содержание всегда начинается со страницы 6;
- идентификатор ПЗ в верхнем колонтитуле;
- нумерация разделов без точки с абзацного отступа; «Введение» и «Заключение»
  не нумеруются;
- перечисления: тире, `1)`, вложенные `а)` с пропуском букв ё, з, й, о, ч, ь, ы, ъ;
- формулы по центру со сквозной нумерацией справа в круглых скобках;
- подписи «Рисунок 1 – …» внизу по центру и «Таблица 1 – …» над таблицей слева;
- содержание до третьего уровня включительно;
- список источников по ГОСТ Р 7.0.5-2008 со ссылками в квадратных скобках;
- приложения: буквы назначаются автоматически, внутри — своя нумерация
  «Рисунок А.1».

### Про полуторный интервал

Методичка задаёт интервал словом — «полуторный», без числа. Шаблон трактует его
по MS Word: для Times New Roman 14 пт это 24.148 пт на строку, около 30 строк
на полосе.

Это стоит знать, если будете сверяться с чужим LaTeX-шаблоном: команда
`\onehalfspacing` из `setspace` даёт множитель 1.25, а не 1.5 — то есть 21.25 пт
и примерно 35 строк на странице. Разница около 13 % по объёму, а «полуторным»
такой интервал не является.

Прежде чем писать текст, соберите витрину и сверьте её с методичкой:

```sh
typst compile examples/showcase.typ
```

## Как писать текст

### Заголовки

```typst
= Раздел          // 1
== Подраздел      // 1.1
=== Пункт         // 1.1.1
```

Ненумерованные разделы (Введение, Заключение):

```typst
#import "../lib/vkr.typ": unnumbered
#unnumbered[Введение]
```

### Рисунки

```typst
#figure(
  image("../assets/figures/scheme.svg", width: 100%),
  caption: [Название рисунка],
) <fig-scheme>
```

Ссылка в тексте — `@fig-scheme` даёт «рисунок 1», как требует методичка для
именительного падежа. Если слово нужно просклонять, сошлитесь только на номер
через `nref` и напишите слово сами:

```typst
#import "../lib/vkr.typ": nref

на рисунке #nref(<fig-scheme>)   // → на рисунке 1
в таблице #nref(<tbl-metrics>)   // → в таблице 1
```

Отдельного пакета для склонений в Typst нет — и он тут не нужен: слово всё
равно пишется руками, а `nref` подставляет только номер.

### Таблицы

```typst
#figure(
  table(
    columns: (auto, 1fr),
    [*Параметр*], [*Значение*],
    [Время отклика], [124 мс],
  ),
  caption: [Название таблицы],
) <tbl-metrics>
```

### Формулы

```typst
$ F = sum_(i=1)^n w_i dot x_i, $ <eq-objective>

где $w_i$ — вес $i$-го критерия.
```

Ссылка `@eq-objective` даёт «(1)».

### Источники

Добавьте запись в `bibliography/references.bib` и сошлитесь ключом:

```typst
существующие подходы @example-article рассматривают …
```

Оформление по ГОСТ применяется само. Требования методички: не менее
30 источников, из них не менее 20 % зарубежных, и на каждый источник в тексте
должна быть ссылка.

#### Типы записей — важно

Используйте только стандартные типы BibLaTeX. Чаще всего нужны четыре:

| Тип | Для чего |
|---|---|
| `@online` | сайты, документация, arXiv — всё, что с URL |
| `@article` | статьи в журналах и сборниках |
| `@book` | книги, учебники, монографии |
| `@misc` | стандарты, ГОСТы, RFC |

Нестандартные типы (например `@REFERENCE`, который понимает LaTeX через алиас)
Typst молча не распознаёт — и **тихо теряет URL с датой обращения**, что
нормоконтроль заметит сразу. Если вы переносите `.bib` из LaTeX-проекта,
проверьте типы:

```sh
grep -oE '^@[a-zA-Z]+' bibliography/references.bib | sort | uniq -c
sed -i '' 's/@REFERENCE/@online/g' bibliography/references.bib   # macOS
sed -i    's/@REFERENCE/@online/g' bibliography/references.bib   # Linux
```

Для `@online` заполняйте `url` и `urldate` — иначе не будет «(дата обращения: …)»:

```bibtex
@online{litestar,
  title   = {Litestar Documentation — Version 2},
  url     = {https://docs.litestar.dev/2/},
  urldate = {2026-05-12},
}
```

#### Стиль ГОСТ

Библиография собирается по `lib/csl/gost-r-705-2008-numeric.csl` — это
официальный стиль с двумя правками под кафедру:

1. **Диапазон страниц.** Встроенный в Typst вариант выводит «Сс. 311–317»,
   хотя по ГОСТ верно «С. 311–317».
2. **`[Электронный ресурс]`** после заголовка убран — на кафедре принято его
   не ставить.

Обе правки помечены в файле комментариями с указанием, как вернуть исходное
поведение.

### Приложения

```typst
#import "../lib/vkr.typ": appendix

#appendix[Название приложения][
  Текст приложения.
]
```

Буквы назначаются по порядку подключения в `thesis.typ` — вставили новое
приложение в середину, остальные перенумеровались сами.

## Титульный лист и задание

Титульный лист и задание (две страницы) выдаются на кафедре в готовом виде.
Отсканируйте их в один PDF, положите в `other/title-and-task.pdf`
и раскомментируйте в `thesis.typ`:

```typst
#import "@preview/muchpdf:0.1.1": muchpdf
...
title-pages: muchpdf(read("other/title-and-task.pdf", encoding: none)),
```

Пока файла нет, подставляются три страницы-заглушки — сквозная нумерация
всё равно остаётся правильной.

## Сборка в GitHub Actions

При каждом push собирается PDF и прикладывается к запуску как артефакт —
удобно, чтобы научный руководитель видел актуальную версию без установки чего
бы то ни было. Настроено в `.github/workflows/build.yml`.

## О шрифтах

Times New Roman не распространяется свободно, поэтому в репозиторий он
не входит. На Windows и macOS он есть в системе — ничего делать не нужно.

На Linux и в CI используется метрически совместимый Liberation Serif:

```sh
sudo apt install fonts-liberation
```

Если хотите использовать именно Times New Roman локально, положите файлы
шрифта в папку `fonts/` (она в `.gitignore`) и собирайте так:

```sh
typst watch thesis.typ --font-path fonts
```

## Проверка перед сдачей

- [ ] объём ПЗ 50–60 страниц без учёта приложений;
- [ ] не менее 30 источников, не менее 20 % зарубежных;
- [ ] на каждый источник, рисунок, таблицу и приложение есть ссылка в тексте;
- [ ] аннотации на русском и английском заполнены, английская не машинная;
- [ ] идентификатор в колонтитуле содержит реальные номер приказа и год;
- [ ] титульный лист и задание вставлены;
- [ ] оригинальность в «Антиплагиате» не ниже 50 %.
